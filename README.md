# AURA Athletics & Performance Club

![Aura Fitness](./Aura_Fitness.png)

A high-performance, contemporary fitness and athletic club web application built with **React**, **TypeScript**, and **Tailwind CSS**.

## Features

- **Modern Architectural Visual Identity**: High-contrast obsidian and emerald palette (`#090A0F` / `#10B981`) paired with clean typography (`Syne` display headers and `Plus Jakarta Sans`).
- **Sleek, Minimalist Navigation Bar**: Frosted glass header bar with smooth section navigation, mobile drawer menu, and quick switching between the Club Overview and the Instruments Showcase.
- **Hero Slider & Facility Metrics**: High-resolution performance photography with auto-advancing slides and real-time facility metrics (30,000 sq.ft, 140+ precision machines, 8 Olympic platforms, 24/7 keyless entry).
- **Instruments & Facilities Showcase Page**:
  - Dedicated showcase highlighting 4 specialized performance zones (Biomechanical Strength Arena, Metabolic & Endurance Deck, Athletic Sprint Turf & Combat, Hydrotherapy & Recovery Sanctuary).
  - Search and filter by category (Strength, Cardio, Functional Turf, Recovery Spa) or search by machine, brand, and target muscles.
  - Interactive specification modals detailing mechanical dimensions, tolerances, target muscle groups, and coach notes.
- **Biomechanical Coaches Directory**: Professional profiles of CSCS coaches, physical therapists, and Olympic lifting specialists with credentials and assessment booking.
- **Verified Member Reviews**: Interactive athlete testimonial slider with verified athlete badges.
- **VIP Facility Tour Modal**: Interactive scheduling form for booking private facility walkthroughs and 1-day testing passes.
- **Clean Button Interactions**: Streamlined, professional button states without bouncy transforms or spinning icons.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
